# Python Programming & OOP — 3-Month Learning Plan 🐍

**Target Audience:** Complete beginners aged 18+
**Python Version:** 3.13
**Time Commitment:** ~5-8 hours per week
**End Goal:** Understand core programming and OOP concepts, and build a fully functional **Personal Budget Tracker** application from scratch.

---

## About Your Project: Personal Budget Tracker 💸

Throughout this plan, you'll progressively build a **Personal Budget Tracker** — a command-line application that lets you add income and expenses, categorize transactions, set budgets, view summaries, and save/load your data. Each week adds new functionality using the concepts you just learned. By the end, you'll have a complete, working app you built yourself.

## Recommended Before You Start

- **Study in short, regular sessions.** Aim for 3-4 sessions per week instead of one long cram session.
- **Type every example yourself.** Reading code helps, but typing it builds real familiarity.
- **Keep one Python folder for the full course.** Staying organized makes it much easier to track your progress.
- **Save weekly checkpoints.** Use Git or simple dated backups so you can return to an earlier working version.
- **Keep a tiny learning log.** After each study session, write down what you learned, what confused you, and one thing to practice next.
- **Test small changes often.** Run your code frequently so mistakes stay small and easier to fix.
