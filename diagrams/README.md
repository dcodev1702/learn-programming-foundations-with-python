# Diagrams

Every diagram in this folder is generated by `python .tooling/generate_diagrams.py`. Edit the builder
functions in `.tooling/diagrams_month*.py` and rerun the script — do not hand-edit the SVG files, your
changes will be overwritten on the next build.

The shared theme (palette, cards, arrows, callouts, code blocks) lives in `.tooling/diagram_kit.py`.
